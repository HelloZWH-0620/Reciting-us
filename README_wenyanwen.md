## 项目缘起

「背书哇！」者，专为高中语文文言诗词背诵而设之本地网页应用也。集课文研习、多方习练、AI 辅弼出题、间隔重复记忆、学业统计诸能于一体，助学子高效掌握必背篇目。

其架构乃纯前端单页应用，无须 Node.js 诸般依赖，但凭 Windows PowerShell 即可起本地服务器。凡数据悉存于浏览器 localStorage，隐私固安，无须注册账号。

### 核心特色

- 📚 **课文丰赡** — 收录高中必背文言文与古诗词，具原文、译文、注释与赏析
- ✍️ **习练多方** — 填空默写、上下句对接、情境默写、虚词通关、词语通关、词类活用等
- 🤖 **AI 辅弼** — 具 AI 语法检校、AI 智能出题之能（须配置外部 AI API）
- 🔄 **间隔重复** — 依艾宾浩斯遗忘曲线设闪卡复习与错题本
- 📊 **学业统计** — 以折线、柱状、饼、热力诸图可视化学习数据
- 🎨 **壁纸随心** — 可自上传背景壁纸，管理之，定时切换之
- 💾 **数据经管** — 学习进度可导出导入，便于多设备同步

## 功能概览

### 一、课文学习

应用所含课文，凡二类：

| 类 | 释 |
|------|------|
| **文言文** | 《论语十二章》《劝学》《屈原列传》《谏太宗十思疏》《师说》《阿房宫赋》《六国论》等经典篇目 |
| **古诗词** | 《春江花月夜》《短歌行》《念奴娇·赤壁怀古》等必背诗词 |

每篇课文，具以下学习模式：

- **显示模式** — 全示原文、译文、注释与赏析
- **背诵模式** — 逐句逐段诵习，隐其部分以助记忆
- **练习模式** — 据当前课文生成习题
- **词语模式** — 重点字词释义与词类活用辨析

### 二、互动练习

所设练习题型甚夥，覆盖高考文言文考点：

| 练习类型 | 释 |
|----------|------|
| **填空默写** | 依上下文填所缺之句，练名句默写之能 |
| **上下句对接** | 出上句或下句，配其另一半 |
| **情境默写** | 模拟高考情境，依提示书相关名句 |
| **虚词通关** | 就一十八个常见文言虚词（而、何、乎、乃、其、且、若、所、为、焉、也、以等）作选择与辨析练习 |
| **词语通关** | 重点实词释义与用法之练习 |
| **词类活用** | 词类活用辨析（名词作状语、使动用法、意动用法等） |

题库之中，预置之题凡 **七十有二**，盖三类：

- **虚词辨析**（一十八题）：选择题也，辨虚词于特定语境中之用法
- **填空默写**（三十六题）：依提示补全经典之句
- **例句匹配**（一十八题）：依虚词释义配正确例句

此外，启用 AI 之能后，可由 AI 动态生成更多题目。

### 三、AI 辅弼之能

应用内置 AI 代理（由本地服务器转发请求），支持以下 AI 之能：

- ✨ **AI 语法检校** — 对用户所输入之文言文句作语法分析
- ✨ **AI 虚词出题** — AI 就全部文言虚词智能生成练习题
- ✨ **AI 情境默写出题** — AI 据课文内容生成情境默写题

> **注意**：AI 之能须配置外部 AI API（如 OpenAI 兼容接口），于应用设置中填入 API 地址与密钥方可用之。

### 四、记诵与温习

- **闪卡系统** — 依间隔重复算法之闪卡复习，科学安排温习之时
- **错题本** — 自动收录练习中之错题，专设错题复习模式
- **背诵进度追踪** — 标记每篇课文掌握之态（已背/未掌握），实时显示学习进度
- **每日复习提醒** — 依遗忘曲线推算下次温习之时

### 五、学业统计

应用内置数据可视化模块，提供以下统计图表：

- 📈 **折线图** — 示每日练习量变化之趋势
- 📊 **柱状图** — 各类练习正确率之对比
- 🥧 **饼图** — 练习类型分布之占比
- 🗺️ **热力图** — 学习活跃度之日历

### 六、作者与朝代

- **作者详情** — 收录经典作者一十八位（孔子、荀子、司马迁、韩愈、苏轼等）之朝代与生平简介
- **朝代卡片** — 按历史朝代浏览相关作者与作品
- **在线查询** — 可跳转外部资源以进一步了解

### 七、随心之设

- 🖼️ **自定义壁纸** — 上传本地图片为应用背景，支持 PNG/JPG/GIF/WebP/BMP 诸格式
- ⏰ **壁纸轮播** — 定时自动切换壁纸
- 🔤 **自定义字体** — 内置 Regular.ttf 字体，安装后阅读体验更佳
- 📝 **笔记批注** — 于课文上添加个人笔记
- 📏 **字体大小调节** — 可调整正文字体大小

### 八、数据经管

- 📤 **数据导出** — 将学习进度、错题记录等数据导出为文件
- 📥 **数据导入** — 自文件导入学习数据，恢复学习进度
- 🗑️ **数据重置** — 一键清除所有本地数据

```
Reciting-us/
├── README.md                          # 项目说明文档
├── __psserver.ps1                     # 简易 PowerShell 测试服务器（开发用）
└── Memorization UI/

    ├── package.ps1                    # 安装引导脚本（创建桌面/开始菜单快捷方式）
    ├── config/

    │   ├── articles.json              # 课文数据（文言文 + 古诗词，含原文、译文、注释、赏析）
    │   ├── poem.json                  # 古诗词数据（独立诗词集）

    ├── resource/
    │   ├── OOBE/                      # 开箱引导图片（page1.png ~ page3.png）

    │   └── wordtype/                  # 字体文件（Regular.ttf）
    └── setuptools/
        ├── server.ps1                 # 本地 PowerShell HTTP 服务器（提供静态文件 + API）
        ├── start.bat                  # 启动脚本（启动服务器 + 打开浏览器）
        ├── config.json                # 安装后自动生成的配置文件（记录项目路径）
        ├── Setup.png                  # 安装引导画面图片
        └── logoblack.ico              # 应用图标
```

## 用法

### 所需环境

- **操作系统**：Windows 7 及以上
- **运行时**：Windows PowerShell（系统自带）
- **浏览器**：Chrome、Edge、Firefox 等现代浏览器（推荐 Chrome 或 Edge）
- **网络**：离线可用（AI 之能需联网）

### 其一：一键安装（荐）

1. **下载此项目**
   ```bash
   git clone https://github.com/HelloZWH-0620/Reciting-us.git
   ```

2. **运行安装脚本**

   双击 `Memorization UI/setup.bat`，脚本将自动完成以下诸事：
   - 安装自定义字体（Regular.ttf）于系统
   - 创建桌面快捷方式「背书哇」
   - 创建开始菜单快捷方式「背书哇」
   - 于屏幕中央显示安装引导画面

3. **启动应用**

   安装既成，双击桌面或开始菜单中「背书哇」快捷方式即可启动。应用将自动：
   - 启动本地 HTTP 服务器（端口八千）
   - 打开浏览器访问 `http://localhost:8000/app.html`

### 其二：手动启动

若不愿创建快捷方式，亦可手动启动：

1. 打开 PowerShell，进入 `Memorization UI/setuptools` 目录：
   ```powershell
   cd "Memorization UI/setuptools"
   ```

2. 运行启动脚本：
   ```powershell
   .\start.bat
   ```

   该脚本将：
   - 将上级目录写入 `config.json`
   - 启动 PowerShell 服务器（默认端口八千）
   - 待二秒后自动打开浏览器

3. 或直接以 PowerShell 启动服务器（可自定义端口）：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "Memorization UI/setuptools/server.ps1" [端口号]
   ```

   然后于浏览器中访问 `http://localhost:端口号/app.html`。

### 其三：开发模式

项目根目录下有简易 PowerShell 服务器 `__psserver.ps1`，可用于快速测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File __psserver.ps1
```

> 该脚本监听端口八千七百六十五，仅提供静态文件服务，不支持壁纸上传等 API 之能。

## 初用指南

1. **开箱引导（OOBE）** — 首次打开应用将进入引导流程，介绍主要功能
2. **浏览课文** — 于侧边栏选择课文分类（文言文/古诗词），点击篇目进入学习
3. **切换学习模式** — 于课文页面顶部切换「显示/背诵/练习/词语」模式
4. **开始练习** — 进入「互动练习」页面，选择练习类型开始答题
5. **查看统计** — 于统计页面查看学习数据图表
6. **自定义壁纸** — 于设置中上传喜爱之图片作为应用背景

---

## 配置 AI 之能

AI 功能通过本地服务器代理转发请求，绕过浏览器 CORS 之限。配置步骤如下：

1. 于应用设置页面寻得 AI 配置选项
2. 填入所用 AI API 地址（兼容 OpenAI 接口格式）
3. 填入 API 密钥
4. 选择模型名称
5. 保存配置后，即可使用 AI 出题、语法检校等能

## 本地服务器 API

`setuptools/server.ps1` 提供以下 API 接口：

| 接口 | 法 | 释 |
|------|------|------|
| `/api/wallpapers` | GET | 获取壁纸文件列表 |
| `/api/upload-wallpaper` | POST | 上传壁纸图片（Base64 格式） |
| `/api/wallpapers/{filename}` | DELETE | 删除指定壁纸 |
| `/api/ai-proxy` | POST | AI 请求代理转发（绕过 CORS） |
| 其他路径 | GET | 静态文件服务 |

## 参与之法

欢迎诸君贡献！可经以下途径参与：

1. **补充课文数据** — 于 `config/articles.json` 或 `config/poem.json` 中添加新的课文内容
2. **添加练习题目** — 于 `config/game.json` 中添加新的练习题
3. **完善作者信息** — 于 `config/writer.json` 中补充或修正作者资料
4. **提交 Issue** — 报告 Bug 或提出功能建议
5. **提交 Pull Request** — 修复问题或开发新功能

### 添加课文之格式

于 `config/articles.json` 之 `articles` 数组中添加新对象：

```json
{
  "id": "唯一标识",
  "title": "课文标题",
  "author": "作者",
  "authorId": "对应 writer.json 中的 id",
  "cat": "wenyanwen 或 gushici",
  "audio": "",
  "text": "课文原文（段落间用 \\n\\n 分隔）"
}
```
