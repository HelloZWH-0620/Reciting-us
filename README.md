# 背书哇！

> 一款帮助中国高中生背诵和学习文言文与古诗词的辅助工具

**当前版本：0.2.2（开发中）**

![License](https://img.shields.io/badge/license-MIT-green)

## 项目介绍

「背书哇！」是一款专为高中语文文言文和古诗词背诵设计的本地 Web 应用。它集课文学习、多种练习模式、AI 辅助出题、间隔重复记忆、学习统计等功能于一体，帮助高中学生高效掌握必背篇目。

项目采用纯前端单页应用架构，无需安装 Node.js 等依赖，仅需 Windows PowerShell 即可运行本地服务器。所有数据存储在浏览器 localStorage 中，隐私安全，无需注册账号。

### 核心特色

- 📚 **丰富的课文库** — 收录高中必背文言文与古诗词，含原文、译文、注释与赏析
- ✍️ **多种练习模式** — 填空默写、上下句对接、情境默写、飞花令、虚词通关、词语通关、词类活用等
- 🤖 **AI 辅助** — 支持 AI 语法检查、AI 智能出题（需配置外部 AI API）
- 🔄 **间隔重复** — 基于艾宾浩斯遗忘曲线的闪卡复习与错题本功能
- 📊 **学习统计** — 可视化折线图、柱状图、饼图、热力图展示学习数据
- 🎨 **个性化壁纸** — 支持自定义背景壁纸上传、管理与定时切换
- 💾 **数据管理** — 支持学习进度导出与导入，方便多设备同步

## 功能概览

### 1. 课文学习

应用包含两大类课文内容：

| 分类 | 说明 |
|------|------|
| **文言文** | 《论语十二章》《劝学》《屈原列传》《谏太宗十思疏》《师说》《阿房宫赋》《六国论》等经典篇目 |
| **古诗词** | 《春江花月夜》《短歌行》《念奴娇·赤壁怀古》等必背诗词 |

每篇课文提供以下学习模式：

- **显示模式** — 完整展示原文、译文、注释与赏析
- **背诵模式** — 逐句/逐段背诵练习，隐藏部分内容辅助记忆
- **练习模式** — 基于当前课文生成练习题
- **词语模式** — 重点字词释义与词类活用分析

### 2. 互动练习

提供多种练习题型，覆盖高考文言文考点：

| 练习类型 | 说明 |
|----------|------|
| **填空默写** | 根据上下文填写缺失的句子，训练名句默写能力 |
| **上下句对接** | 给出上句或下句，匹配对应的另一半 |
| **情境默写** | 模拟高考情境，根据提示写出相关名句 |
| **飞花令** | 限时说出含指定字的古诗文，连击挑战（基于已收录篇目自动生成字库） |
| **虚词通关** | 针对 18 个常见文言虚词（而、何、乎、乃、其、且、若、所、为、焉、也、以等）的选择与辨析练习 |
| **词语通关** | 重点实词的释义与用法练习 |
| **词类活用** | 词类活用辨析（名词作状语、使动用法、意动用法等） |

题库包含 **72 道预置题目**，涵盖三类题型：
- **虚词辨析**（18 题）：选择题，判断虚词在特定语境中的用法
- **填空默写**（36 题）：根据提示补全经典句子
- **例句匹配**（18 题）：根据虚词释义匹配正确例句

此外，启用 AI 功能后可由 AI 动态生成更多练习题目。

### 3. AI 辅助功能

应用内置 AI 代理（通过本地服务器转发请求），支持以下 AI 功能：

- ✨ **AI 语法检查** — 对用户输入的文言文句子进行语法分析
- ✨ **AI 虚词出题** — AI 针对全部文言虚词智能生成练习题
- ✨ **AI 情境默写出题** — AI 根据课文内容生成情境默写题

> **注意**：AI 功能需要配置外部 AI API（如 OpenAI 兼容接口），需在应用设置中填入 API 地址和密钥。

### 4. 记忆与复习

- **闪卡系统** — 支持基于间隔重复算法的闪卡复习，科学安排复习时间
- **错题本** — 自动收录练习中的错题，支持专门的错题复习模式
- **背诵进度追踪** — 标记每篇课文的掌握状态（已背/未掌握），实时显示学习进度
- **每日复习提醒** — 基于遗忘曲线计算下次复习时间

### 5. 学习统计

应用内置数据可视化模块，提供以下统计图表：

- 📈 **折线图** — 展示每日练习量变化趋势
- 📊 **柱状图** — 各类练习正确率对比
- 🥧 **饼图** — 练习类型分布占比
- 🗺️ **热力图** — 学习活跃度日历

### 6. 作者与朝代

- **作者详情** — 收录 18 位经典作者（孔子、荀子、司马迁、韩愈、苏轼等）的朝代与生平简介
- **朝代卡片** — 按历史朝代浏览相关作者与作品
- **在线查询** — 支持跳转外部资源进一步了解

### 7. 个性化设置

- 🖼️ **自定义壁纸** — 上传本地图片作为应用背景，支持 PNG/JPG/GIF/WebP/BMP 格式
- ⏰ **壁纸轮播** — 支持定时自动切换壁纸
- 🔤 **自定义字体** — 内置 Regular.ttf 字体，安装后获得更好的阅读体验
- 📝 **笔记批注** — 在课文上添加个人笔记
- 📏 **字体大小调节** — 支持调整正文字体大小

### 8. 数据管理

- 📤 **数据导出** — 将学习进度、错题记录等数据导出为文件
- 📥 **数据导入** — 从文件导入学习数据，恢复学习进度
- 🗑️ **数据重置** — 一键清除所有本地数据

## 项目结构

> [!important] 
> 项目仍在测试阶段，结构会不定期改动。此处的项目结构不代表最终结构。

```
Reciting-us/
├── README.md                          # 项目说明文档
├── __psserver.ps1                     # 简易 PowerShell 测试服务器（开发用）
└── Memorization UI/
    ├── app.html                       # 主应用（单页应用，含所有前端逻辑）
    ├── setup.bat                      # 一键安装脚本（安装字体 + 启动服务器）
    ├── package.ps1                    # 安装引导脚本（创建桌面/开始菜单快捷方式）
    ├── config/
    │   ├── manifest.json              # PWA 应用清单（应用名称、图标等）
    │   ├── articles.json              # 课文数据（文言文 + 古诗词，含原文、译文、注释、赏析）
    │   ├── poem.json                  # 古诗词数据（独立诗词集）
    │   ├── game.json                  # 练习题库（72 道题目，含虚词辨析、填空默写、例句匹配）
    │   └── writer.json                # 作者信息（18 位作者的朝代与生平简介）
    ├── resource/
    │   ├── OOBE/                      # 开箱引导图片（page1.png ~ page3.png）
    │   ├── background/                # 壁纸资源目录（默认 Default.jpg）
    │   └── wordtype/                  # 字体文件（Regular.ttf）
    └── setuptools/
        ├── server.ps1                 # 本地 PowerShell HTTP 服务器（提供静态文件 + API）
        ├── start.bat                  # 启动脚本（启动服务器 + 打开浏览器）
        ├── config.json                # 安装后自动生成的配置文件（记录项目路径）
        ├── Setup.png                  # 安装引导画面图片
        └── logoblack.ico              # 应用图标
```

## 使用方法

### 环境要求

- **操作系统**：Windows 7 及以上
- **运行时**：Windows PowerShell（系统自带）
- **浏览器**：Chrome、Edge、Firefox 等现代浏览器（推荐使用 Chrome 或 Edge）
- **网络**：离线可用（AI 功能需要联网）

### 方式一：一键安装（推荐）

1. **下载项目**
   ```bash
   git clone https://github.com/HelloZWH-0620/Reciting-us.git
   ```

2. **运行安装脚本**

   双击 `Memorization UI/setup.bat`，脚本会自动完成以下操作：
   - 安装自定义字体（Regular.ttf）到系统
   - 创建桌面快捷方式「背书哇」
   - 创建开始菜单快捷方式「背书哇」
   - 在屏幕中央显示安装引导画面

3. **启动应用**

   安装完成后，双击桌面或开始菜单中的「背书哇」快捷方式即可启动。应用会自动：
   - 启动本地 HTTP 服务器（端口 8000）
   - 打开浏览器访问 `http://localhost:8000/app.html`

### 方式二：手动启动

如果不想创建快捷方式，也可以手动启动：

1. 打开 PowerShell，进入 `Memorization UI/setuptools` 目录：
   ```powershell
   cd "Memorization UI/setuptools"
   ```

2. 运行启动脚本：
   ```powershell
   .\start.bat
   ```

   该脚本会：
   - 将上级目录写入 `config.json`
   - 启动 PowerShell 服务器（默认端口 8000）
   - 等待 2 秒后自动打开浏览器

3. 或直接使用 PowerShell 启动服务器（可自定义端口）：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "Memorization UI/setuptools/server.ps1" [端口号]
   ```

   然后在浏览器中访问 `http://localhost:端口号/app.html`。

### 方式三：开发模式

项目根目录下有一个简易的 PowerShell 服务器 `__psserver.ps1`，可用于快速测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File __psserver.ps1
```

> 该脚本监听端口 8765，仅提供静态文件服务，不支持壁纸上传等 API 功能。

## 首次使用指南

1. **开箱引导（OOBE）** — 首次打开应用会进入引导流程，介绍主要功能
2. **浏览课文** — 在侧边栏选择课文分类（文言文/古诗词），点击篇目进入学习
3. **切换学习模式** — 在课文页面顶部切换「显示/背诵/练习/词语」模式
4. **开始练习** — 进入「互动练习」页面，选择练习类型开始答题
5. **查看统计** — 在统计页面查看学习数据图表
6. **自定义壁纸** — 在设置中上传喜欢的图片作为应用背景

---

## 配置 AI 功能

AI 功能通过本地服务器代理转发请求，绕过浏览器 CORS 限制。配置步骤：

1. 在应用的设置页面找到 AI 配置选项
2. 填入你使用的 AI API 地址（兼容 OpenAI 接口格式）
3. 填入 API 密钥
4. 选择模型名称
5. 保存配置后即可使用 AI 出题、语法检查等功能

| 组件 | 技术 |
|------|------|
| 前端 | 纯 HTML/CSS/JavaScript（单文件应用） |

## 本地服务器 API

`setuptools/server.ps1` 提供以下 API 接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/wallpapers` | GET | 获取壁纸文件列表 |
| `/api/upload-wallpaper` | POST | 上传壁纸图片（Base64 格式） |
| `/api/wallpapers/{filename}` | DELETE | 删除指定壁纸 |
| `/api/ai-proxy` | POST | AI 请求代理转发（绕过 CORS） |
| 其他路径 | GET | 静态文件服务 |

## 贡献指南

欢迎贡献！你可以通过以下方式参与：

1. **补充课文数据** — 在 `config/articles.json` 或 `config/poem.json` 中添加新的课文内容
2. **添加练习题目** — 在 `config/game.json` 中添加新的练习题
3. **完善作者信息** — 在 `config/writer.json` 中补充或修正作者资料
4. **提交 Issue** — 报告 Bug 或提出功能建议
5. **提交 Pull Request** — 修复问题或开发新功能

### 添加课文的格式

在 `config/articles.json` 的 `articles` 数组中添加新对象：

```json
{
  "id": "唯一标识",
  "title": "课文标题",
  "author": "作者",
  "authorId": "对应 writer.json 中的 id",
  "cat": "wenyanwen 或 gushici",
  "audio": "",
  "text": "课文原文（段落间用 \\n\\n 分隔）"
}
```
